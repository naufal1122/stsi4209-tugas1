Aplikasi Pemesanan Bahan Ajar SITTA UT Berbasis Vue.js

Selamat datang pada portal aplikasi web pemesanan dan distribusi bahan ajar (BMP) SITTA Universitas Terbuka. Aplikasi ini dibangun secara murni menggunakan framework JavaScript Vue.js untuk antarmuka interaktif, reaktivitas data, dan pelacakan DO yang mutakhir.

Buka Halaman 1: Stok Bahan Ajar → Buka Halaman 2: Tracking DO →

Navigasi Dua Halaman Aplikasi (Wajib)

Silakan pilih salah satu modul aplikasi web yang ingin diakses:

Halaman 1 (Wajib)

Stok Bahan Ajar BMP

Menampilkan inventaris bahan ajar untuk seluruh UT-Daerah lengkap dengan sistem filter cerdas, dependent dropdown, status re-order, fitur edit stok, dan formulir input data baru.

  • ✔ Filter & Sort Caching: Menggunakan computed property tanpa recompute berulang.
  • ✔ Dependent Options: Filter Kategori muncul setelah UT-Daerah dipilih.
  • ✔ Status Visual: Aman (Hijau), Menipis (Orange), Kosong (Merah) via v-if.
  • ✔ Catatan HTML: Directive v-html untuk styling catatan.
  • ✔ Watchers & Storage: Otomatis simpan stok ke localStorage.
Akses Halaman Stok Bahan Ajar →
Halaman 2 (Wajib)

Tracking Delivery Order (DO)

Melacak status dan riwayat pengiriman paket BMP mahasiswa secara terperinci serta menyediakan formulir penerbitan Delivery Order baru dengan auto-generated number.

  • ✔ Auto Nomor DO: Tergenerate otomatis DO[Tahun]-[Sequence].
  • ✔ Detail Paket Interaktif: Muncul informasi modul lengkap di bawah elemen <select>.
  • ✔ Total Harga Reaktif: Terisi otomatis dari paket.harga saat paket dipilih.
  • ✔ Tanggal Otomatis: Mendukung tanggal manual maupun objek Date() lokal.
  • ✔ Timeline Ekspedisi: Menampilkan riwayat perjalanan lengkap step-by-step.

Matriks Pemenuhan 5 Indikator Capaian Tugas Praktik 2

Panduan ringkas untuk mempermudah penilaian dan referensi pembuatan rekaman video penjelasan (maksimal 15 menit):

Indikator Capaian Penerapan pada Stok Bahan Ajar (stok.html) Penerapan pada Tracking DO (tracking.html)
1. Pengorganisasian Kode Vue.js Struktur Vue instance bersih di js/stok-app.js: data, computed, methods, watch, mounted. Struktur Vue instance di js/tracking-app.js terpisah rapi dengan modul data terpusat di dataBahanAjar.js.
2. Menampilkan Data (Mustaches, v-text, v-html) - Mustaches {{ }} pada kolom tabel.
- v-text untuk ringkasan filter teks.
- v-html untuk kolom catatanHTML (<em>, <strong>, <u>). 		- Mustaches {{ }} pada detail NIM, Nama, Total Harga.
- v-for untuk render list paket, DO, dan riwayat perjalanan ekspedisi.
3. Penggunaan Conditional (v-if, v-else-if, v-else, v-show) - v-if / v-else-if / v-else pada Status Stok (Aman, Menipis, Kosong).
- v-if pada dependent filter Kategori.
- v-show pada formulir tambah & notifikasi toast. 		- v-if="currentDO" untuk menampilkan data pelacakan.
- v-else-if untuk pesan DO tidak ditemukan.
- v-if="selectedPaketDetail" untuk detail isi paket di bawah dropdown.
4. Data Binding & Property (Computed & Methods) - v-model pada filter & formulir.
- computed: filteredStok meng-cache filter & sort tanpa recompute.
- methods: resetFilter, tambahStok, editStok, hapusStok, formatRupiah. 		- v-model two-way binding pada form input.
- computed: nextNomorDO auto-generate DO[Tahun]-[Seq].
- computed: selectedPaketDetail mengambil info isi paket.
5. Fungsi Watchers (≥ 2 Watcher) - Watcher 1: Memantau filterUpbjj (reset kategori saat UT daerah berubah).
- Watcher 2: Deep watch pada stok untuk persistensi otomatis ke localStorage. 		- Watcher 1: Memantau formDO.paketKode (sinkronisasi harga paket otomatis).
- Watcher 2: Deep watch trackingData ke localStorage & auto-search watcher.
6. Formulir & Validasi Input Formulir input bahan ajar baru dengan validasi field kode, judul, upbjj, kategori, harga, qty, safety, dan feedback visual. Formulir penerbitan DO baru dengan validasi NIM numerik, Nama, Ekspedisi, Paket BMP, dan tanggal kirim lokal.
